Questions

Do I need a computer?

On iOS 27 or later, no: the iPhone pairs with itself. From iOS 17.4 to 26.7 you need a pairing file made once on a computer, and from iOS 26.4 it has to be a remote pairing file.

What each iOS version needs

Is it safe to type in my Apple ID?

In the official app, yes. Your Apple ID is used on the device, only to sign and install your apps. Nothing is logged or collected: SideInstaller has no server, no analytics and no account. The code is public, so anyone can check.

That holds for the app from sideinstaller.net or its GitHub repository. A copy from anywhere else, sideinstaller.com included, may have been changed to steal what you type into it.

Which certificate should I pick?

You only need one for the Legacy install; the three steps sign SideInstaller with your own Apple Account. Any of them: they all install the same app, and the ones marked Valid come first. If the app won't open, or its certificate is revoked later, go back to the install page and use another.

What is the DNS profile, and can I remove it?

It's SideInstaller's own DNS, used while you set up with a certificate (the Legacy install). Install it before the app and keep it on until setup is complete.

Once SideStore is installed it's no longer needed. Remove it in Settings › General › VPN & Device Management › SideInstaller › Remove Profile, or keep it and switch DNS back to Automatic in the same menu.

Is SideInstaller part of SideStore?

No. SideInstaller is an independent project and isn't affiliated with SideStore. Please don't ask SideStore's staff about it, as they aren't able to answer. Ask in the SideInstaller Discord.

Does it cost anything?

No. SideInstaller is free and open source. Donations are optional and don't unlock anything.

Can I share a link that installs an app?

Yes. Put the https address of an .ipa, percent-encoded, after https://sideinstaller.net/open.html?url=. Tapping that link opens the file in SideInstaller, which shows where it comes from and asks before downloading anything.
