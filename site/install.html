Install the DNS profile

SideInstaller's own DNS. Keep it on until setup is complete.

Install DNS profile
  1. Tap Install DNS profile and tap Allow when Safari asks to download the configuration profile.
  2. Open Settings and tap Profile Downloaded, or go to Settings › General › VPN & Device Management, then tap Install.
  3. In Settings › General › VPN & Device Management, open DNS and make sure SideInstaller is selected.
2

Install the app

Pick any certificate, tap Install and confirm the prompt. They all install the same app. If one is revoked or the app won't open, install with another.

Open SideInstaller

Open it from your Home Screen and use it to install SideStore, LiveContainer + SideStore, AltStore or Madeira, straight from your device. No computer needed.

Once SideStore is installed, the DNS profile is no longer needed. Remove it in Settings › General › VPN & Device Management › SideInstaller › Remove Profile, or keep it and switch DNS back to Automatic in the same menu.
