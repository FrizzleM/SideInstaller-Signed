Get the apps

Free on the App Store. Needs iOS 27 or later, Wi-Fi and Developer Mode on.

rootshell Open Minis LocalDevVPN
2

Pair

In rootshell.

  1. Turn on Location Diary Mode › Session Only in rootshell's settings.
  2. Tap Local Shell, then Open at the top right.
  3. Run these one at a time:
    curl -fsSLO https://raw.githubusercontent.com/FrizzleM/siboot/main/rootshell/bin/siboot-pair.wasm
    ifconfig en0 > ifconfig.txt
    ./siboot-pair.wasm
  4. In Settings › Privacy & Security › Developer Mode, tap Pair with siboot at the bottom and enter the code rootshell shows. Leave rootshell running.
  5. Go back to rootshell and wait for it to give a second code. When it does, open the Open Minis app.
3

Install

In Open Minis.

  1. Tap the console icon at the top right, then Shell Terminal.
  2. Connect LocalDevVPN, then run:
    wget -qO- https://raw.githubusercontent.com/FrizzleM/siboot/main/minis/install.sh | sh
  3. A page opens over the terminal. On it, enter the transfer code rootshell shows, then sign in with your Apple Account. Keep Minis open until it's done. Closed the page? Press return in the terminal to bring it back.
  4. Trust your Apple Account in Settings › General › VPN & Device Management, then open SideInstaller. The page's Open SideInstaller button does that.
Legacy Enterprise certificates
Install DNS profile
  1. Install the profile in Settings, then select SideInstaller in Settings › General › VPN & Device Management › DNS.
  2. Tap Install on a certificate and trust it in Settings › General › VPN & Device Management. If it won't open, try another.
  3. Once SideStore is installed, remove the DNS profile.

No Developer Mode in Settings?

Connect LocalDevVPN. In Open Minis, tap the console icon at the top right, then Shell Terminal, and run this. Developer Mode then appears in Settings › Privacy & Security › Developer Mode.

wget -qO- https://raw.githubusercontent.com/FrizzleM/siboot/main/minis/install.sh | sh -s developer-mode
